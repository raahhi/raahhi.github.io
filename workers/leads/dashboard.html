Visitor activity

Browsing sessions, including visitors who never enquire. Only activity after analytics consent is recorded. Declined consent, blocked scripts and lost network requests leave gaps. Recorded technical details include the last observed IP address, device category, operating system and browser family/major version. Names, form contents and screen recordings are not collected. An IP address does not prove a person’s identity. A WhatsApp click does not prove a message was sent.

Counts represent sessions, not unique people. Actions are counted independently; visitors can go directly to WhatsApp. Recent activity means seen within 20 minutes. Inactive sessions show the last observed step, not a confirmed reason for leaving. Time is approximate visible-page time; scroll is the deepest observed position.
